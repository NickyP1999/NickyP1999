GIFs for each alert.

By default the overlay hotlinks Cowboy Bebop GIFs from Giphy (set in
js/config.js -> alerts.*.gif), so this folder can stay empty and it still works.

Prefer your own files? Drop them here and point config.js at them, e.g.:
    gif: "gifs/follow.gif"
Local files are more reliable than hotlinks (a hotlinked URL can disappear if
the uploader deletes it) and work even with no internet.

Current default clips:
    follow   -> Spike lighting a cigarette
    sub      -> the crew + the ship (Spike, Jet, Ein, Edward)
    resub    -> Spike: "whatever happens, happens"
    giftSub  -> Edward dancing
    cheer    -> Spike at the bar
    raid     -> Spike smirking
    donation -> "See you, space cowboy..."

Find more: https://giphy.com/search/cowboy-bebop  or  https://tenor.com/search/cowboy-bebop-gifs
